2. AURELIA — Classical Wealth / Private Office

Build a single self-contained HTML application called AURELIA, a sophisticated private wealth and portfolio intelligence interface for a fictional family office.

This is a frontend-only benchmark, entirely contained within one HTML file.

Use an exceptionally refined classical light design system: ivory, parchment, black, graphite, muted brass/champagne accents, restrained deep green or burgundy where appropriate, sophisticated typography, precise grid systems, thin rules, subtle shadows, and tactile surfaces.

The visual language should evoke a private bank, architectural journal, luxury financial report, and modern software product simultaneously.

Do not build a generic fintech dashboard.

The application should have a strong editorial overview that gradually leads into deeper financial information. Include a sophisticated portfolio overview, allocation visualization, market/asset views, holdings, performance history, activity, notes, and detailed asset information using realistic mock data.

The experience should be highly interactive.

Users should be able to:

change portfolio views
inspect holdings
filter assets
switch time ranges
reveal details
explore performance
compare categories
open detailed positions
interact with charts
change contextual settings
navigate through multiple layers of information

Charts and visualizations should feel integrated into the design rather than like generic chart-library components.

Make smooth scrolling and motion central to the experience. As the user moves through the application, information should reveal progressively and the visual hierarchy should evolve naturally.

Create sophisticated transitions between overview and detail states. Panels may expand into full views, charts may transform between representations, and contextual information should appear organically.

Include polished motion for:

scrolling
chart transitions
number changes
filtering
modal/detail expansion
navigation
hover states
focus states
selection
loading
notifications
state changes

Animations should feel quiet, precise, and expensive.

Avoid neon, crypto aesthetics, excessive gradients, generic rounded SaaS cards, giant dashboard grids, and excessive glassmorphism.

Make desktop feel expansive and luxurious while making mobile a genuinely redesigned experience.

Populate the application with enough realistic data and states that it feels like a real product rather than a visual concept.

After the initial implementation, run the application and inspect it visually. Perform multiple rounds of refinement until typography, spacing, transitions, charts, responsiveness, and interaction quality feel cohesive.

The final result should feel like software created by an elite financial product and industrial-design team, not a template.
