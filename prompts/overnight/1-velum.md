VELUM — Digital Museum / Manuscript Archive

Build a single self-contained HTML application called VELUM, an immersive digital archive for rare manuscripts, paintings, maps, and historical objects.

This is a frontend-only benchmark and must be contained entirely within one HTML file.

Use a light classical design system throughout: warm paper and ivory tones, ink, charcoal, muted stone, restrained burgundy/oxide accents, elegant serif typography paired with a refined sans-serif, hairline dividers, editorial spacing, subtle shadows, and carefully controlled depth.

The experience should feel like entering a world-class museum archive, not a conventional website or dashboard.

Create a rich opening experience that transitions naturally into the collection. The page should have strong editorial storytelling, large typography, carefully composed imagery/mock artwork, archival metadata, collection groupings, and detailed object views.

Use smooth scrolling as a major part of the experience. Sections should transition fluidly, with scroll-driven reveals, subtle parallax, typography movement, image transformations, and carefully choreographed changes in hierarchy. Do not use motion simply for decoration; scrolling should feel like moving through an exhibition.

Create an immersive collection browser with meaningful interaction. Users should be able to explore objects, filter or search the archive, open detailed records, inspect metadata, and move between related works.

At least one major interaction should feel distinctive—for example, an object can expand into an archival reading surface, a catalog item can transition into a large editorial view, or relationships between works can be explored spatially.

Use sophisticated animations and micro-interactions throughout:

smooth page transitions
scroll-linked reveals
elegant hover states
image movement
panel expansion
modal transitions
subtle cursor/interaction feedback
progressive disclosure
animated filtering/search
polished loading and empty states

The interface should remain calm despite the amount of information.

Make the experience fully responsive and recompose it intelligently on mobile rather than simply stacking desktop elements.

Use realistic archival content and metadata so the application feels alive and credible.

After implementation, actually run and inspect the page. Perform multiple refinement passes focused on composition, typography, spacing, smoothness of animation, responsiveness, accessibility, and overall visual quality.

Do not finish at "the page works."

The final result should feel like a premium digital museum experience suitable for a design case study.
